# Waxline — CLEANROOM: how the feel was set, number by number

This file ships with the open source as the "how it's done". Every number that sets the feel is listed with where it came from: a
**published** fact (with its link), **derived** from published facts, or **own** tuning (my choice, to be tested by the instruments in
DESIGN.md §1). No number comes from reading another game's code or data: nothing under `ports_src/_ref/`, no unlicensed project (StarKnightt's
skate-park included), no commercial game's files were opened. Started at M0 (2026-10-15); every later milestone adds its rows.

## What was read, and what was not

| Read | Why |
|---|---|
| the builder's brief, the house brief, the loading brief | the rules |
| `reports/Console game remakes for the web.md`, `research_notes/…/skateboarding_games.md` | the published facts below, with their links |
| `_kit/mosa-port.js` (whole), `_kit/drive.mjs`, `_kit/weigh.mjs`, `~/.mosa/heavy.sh` | the tools |
| Dusk Duel, Downtown Dash, Glazeworks, Ochrefall, Stormspan, Tinlight: credits, `port.js`, config heads, shots | the house conventions |
| Ochrefall's `src/gfx/bake.js` head and `src/core/Tier.js` head — MIT (Cinder Ops by StarKnightt) | the IDEAS of painting maps on the GPU from one surface function and of a tier + governor + ledger; nothing copied — my code is written fresh |
| the platform's certification readers (`certifyProbe.js`, `certification.js`, `cli/deviceValidator.js` `_readinessRead`) — read-only | what a phone pass checks, so the game passes it honestly |
| **Not opened** | anything under `_ref/`; StarKnightt's skate-park (no licence); any unlicensed or commercial game's code, data or assets |

## The method, as it will ship

1. Published facts first, each with its link; where none exists, a number of my own, said so.
2. Each own number is held by an instrument (DESIGN.md §1): a Node test, a bot reading, a shot, a weight — and changed only with a new
   measurement written here.
3. No study room was needed: nothing of a commercial game was measured or read. If a measurement of a lawfully owned game is ever wanted
   (pop height from replay footage, as the Physics Education ollie study did), it belongs in its own room and its own section of this file.

## The motion (2026-10-16: the owner, "we need the body movements to be actually natural like the skaters. Its very stiff on the thrust")

biomechanics, the skater's own skeleton and physics. Walled by `tests/motion.mjs` and `tests/motion_sweep.mjs` (every reading over 178
cases: pushes at four speeds and five steers, releases and tricks begun in every phase) on the real sim and the real pose.
